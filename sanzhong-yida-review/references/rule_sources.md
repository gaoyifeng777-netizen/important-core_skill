# 判定规则与潜在线索的来源说明

来源核验记录日期：2026-10-03；预算规则补充核验日期：2026-10-10。本文提供官方来源、条文位置和适用边界，供评价人员维护规则库。规范正文可查不等于已经确认具体企业、治理层级和业务期间的适用性；运行时应取得并核对该企业的制度、授权及业务材料。

## 1. 依据的使用次序

业务规则库中的控制卡先说明可测试的控制命题，再由base_rule结合当时适用的外部要求、章程、制度及授权原件整理正式候选，经人工第二步确认其主体、期间、参数和例外。分析方法、示范指引和公开案例不能单独充当客户违规依据；企业确认也不能排除明确适用的强制要求。

S01—S06为规范来源编号，不把这些编号当成正式企业rule_id。公开案例A01、A02仅启发潜在线索，不说明被评价企业发生相同问题，也不构成对案件当前整改状态的评价。

## 3. 用于业务内容线索的指引位置

下列均来自S02同一份官方PDF。以下为本Skill据指引设计的取证方向，具体检查方法属于评价设计，并非逐字转录条文。

| 指引位置（物理页） | 线索设计方向 | 需要保留的边界 |
|---|---|---|
| 第6号资金活动，第13—15条（23—24页） | 论证条件、资金来源、投资执行与批准内容之间的关系 | 申请中的资金安排不是已落实融资证明；执行证据需另取得 |
| 第7号采购业务，第6—7条（28页） | 需求形成、供应商选择依据及业务合理性 | 不能用供应商名称相似或多份合同直接判定关联或拆分 |
| 第11号工程项目，第5—8、22、27条（45—46、50—51页） | 论证、方案/实施变动、项目后评价反馈 | 是否须重履程序及哪些项目纳入后评价，取决于适用要求 |
| 第15号全面预算，第11、14条（68—69页） | 批准预算与实际安排、偏离及调整说明 | 总投资、年度预算、资金占用和当期现金支付不是同一金额属性 |
| 第16号合同管理，第5、7、8、12条（72—74页） | 相对方能力、关键条款、履行与变更的依据 | 名称更正未必是法律主体变化；会议安排不证明合同已经履行 |

另可按项目需要核验[国资委令第34号《中央企业投资监督管理办法》官方转载](https://www.samr.gov.cn/djzcj/zcfg/qt/art/2023/art_675db49385e64dee807f3f75d84071f4.html)，2017年，第2、11、15、18、21条。其直接对象和投资范围有专门限定；仅用于计划预算衔接、投资论证、过程变化与后评价的研究参考，不直接移植监管层级、报送期限或扩大后评价范围。正文采用所列政府部门完整转载；企业监管关系仍须在本次任务中核实。

## 5. 后续新增案例的登记格式

新增案例至少记：案例编号、官方原页/附件、发布时间与问题发生期间、原对象、事实位置、来源性质、可迁移的中性问题、禁止外推的结论、拟关联规则卡。只看到搜索摘要而未取得正文的，标“待核”，不进入确认依据。现有卡片如因新证据改变判断含义，增版并保留旧版，不因增加一个案例就自动扩大被评价主体的义务。


## 6. 2026-10-10补充：年度初始预算及时性（L11）

2026-10-10核验S02官方83页PDF中的第15号全面预算第5、8、10、11条（物理第67—68页）：分别涉及草案编制、审议批准和下达、年度与分期预算控制、资金收付控制。第五条的草案编制节点不能移植为董事会审批截止日；最终批准权限还须核对企业当期适用的章程和授权。S06的配套指引性质边界继续适用。

L11属于根据上述控制目的设计的分析方法，适用范围为年度初始预算，预算调整仅用于区分事项性质。明确当年初始预算于9月首次批准可以提出时点衔接疑问；9月不是法规或企业统一期限，前期实际支出及控制效果尚需专项证据。具体企业适用性及实际影响须在本次任务中另行核验，不能仅凭本方法认定违规或缺陷。
